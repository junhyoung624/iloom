🪑 일룸(iloom) 웹사이트 리뉴얼 프로젝트

## 📌 프로젝트 소개
일룸 브랜드 웹사이트를 사용자 중심으로 리뉴얼한 팀 프로젝트입니다. 디자인 시스템을 구축하고, 동적 데이터 연동과 회원 관리 기능을 구현하여 실무적인 서비스 완성도를 높이는 데 주력했습니다.

## 🛠 사용 기술 스택
- **Frontend:** React, JavaScript, SCSS, JSX
- **Design/Tool:** Figma
- **Backend/Data:** Firebase (Firestore), 크롤링 기술

## 나의 주요 역할 및 기여
- **디자인 시스템 구축:** UI 디자인 고도화를 통해 팀 프로젝트의 일관된 디자인 시스템을 구축했습니다.
- **제품 서브 페이지 및 동적 렌더링:** `productData`를 활용한 제품 서브 페이지의 동적 렌더링을 구현하고, 탭 UI 및 옵션 선택에 따른 이미지 연동 등 인터랙티브한 기능을 개발했습니다.
- **회원 관리 시스템:** Firebase Firestore를 활용하여 회원가입 및 소셜 로그인(구글, 카카오, 네이버)을 구현했습니다.
- **데이터 전처리 및 기능 구현 :** 색상 이미지 일괄 크롤링 후 `colorData`를 활용하여 상세 옵션 개선했습니다.
- **챗봇 기능 구현 :** openApi를 사용하고 `productData`를 활용하여 챗봇의 대답 기능을 개선했습니다.
